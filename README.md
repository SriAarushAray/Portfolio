# Sri Aarush Aray — Portfolio

A single-file, self-contained portfolio site — animated, dark-themed, and built to highlight deep learning, AI/ML, and full-stack work.

🔗 **Live site:** [sriaarusharay.github.io](https://sriaarusharay.github.io)

---

## About

This is my personal portfolio, showcasing:

- 🎓 M.Tech in Artificial Intelligence, Amrita Vishwa Vidyapeetham
- 🧠 Deep learning & ML research — including an IEEE-sponsored conference publication on cervical cancer classification (95.57% accuracy, ResNetV2)
- 💻 Java-first coding background, with full-stack experience (React, Node.js, MongoDB)
- 🏆 Recognition: NSSC Space Quiz gold prize, AWS Cloud Practitioner certification, SEDS SRMAP co-convenor, community service team lead

## Tech Stack

- **HTML5 / CSS3** — custom properties, responsive grid, no framework
- **Vanilla JavaScript** — canvas-based constellation background, typing animation, scroll-reveal, count-up stats, marquee skill strips
- **Fonts:** [Unbounded](https://fonts.google.com/specimen/Unbounded), [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts

No build step, no dependencies — it's a single `index.html` file with everything (including the profile photo) inlined.

## Running locally

No build tools needed — just open the file:

```bash
git clone https://github.com/SriAarushAray/SriAarushAray.github.io.git
cd SriAarushAray.github.io
open index.html   # or double-click it
```

Hosted via **GitHub Pages**, served directly from the `main` branch.
