This is my **first-year project**, a personal **Portfolio Website** built with **HTML & CSS**.  
It showcases my skills, projects, and achievements in a simple and elegant design.  

---

## 📂 Project Structure  

```bash
Portfolio/
│── index.html         # Main portfolio page
│── about.html         # About Me section
│── projects.html      # Projects showcase
│── contact.html       # Contact form
│── styles.css         # CSS styling
│── assets/            # Images, icons, background graphics
│── README.md          # Project documentation
```

🔧 Installation & Setup

Clone the repo:
```bash
git clone https://github.com/SriAarushAray/Portfolio.git
cd Portfolio
```
Open in browser:
```bash
open index.html
```
